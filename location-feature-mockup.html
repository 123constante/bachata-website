Location on the map — control + pulsing user dot

Three treatments for the blue “locate me” control and the “you are here” dot on the Festival Map homepage. Real dark-theme tokens. The dot is animating live; toggle the located state to see grant → dot + control change. Every approach is wired to the same state.geo (one source of truth: idle / loading / granted / denied).

All three reuse the proven useGeolocation hook + a shared denial-copy module, and the same dot/control respond to one shared state.geo. The dot shows on every tab; the Tonight tab additionally sorts cards by distance and shows teal MI chips. Reduced-motion disables the pulse (the static blue dot + ring remain). Recommended: A — Beacon (most recognisable, calmest), with the louder B or the more-discoverable pill C as alternatives.
