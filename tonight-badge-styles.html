A — Top-right image pill

  • Reads as a status — pairs visually with the LIVE / STARTING SOON pill.
  • Most prominent at-a-glance signal — strong on the proximity-first thesis.
  • Risk: image-dependent contrast, but the backdrop-blur + dark fill mitigates that.

B — Inline on venue row

  • Reads as metadata — semantically tied to the venue it measures from.
  • Quieter; sits beside other facts the user is already scanning.
  • Mirrors the existing pattern in CalendarListView (consistency).
  • Slightly less prominent on mobile — below the image fold.
Both candidates use only Tailwind classes that exist in the codebase. The 4-second loop is animation-only — in the real page the badge appears once on grant and stays put.
