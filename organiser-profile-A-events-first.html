Approach A

Events-first stripped

Compact identity strip in one dense row, then upcoming events as a 3-col grid immediately below the hero. Honours the 3-column mobile directive at full intensity to surface event throughput before anything else.

Above-fold honesty: on a 375×667 mobile (≈587px content visible), the user sees breadcrumb + hero + identity strip + the first row of three event cards before scrolling. Identity is condensed (avatar + name + 3 stat pills + 4 social icons) to keep events visible. Trade-off: 3-col event cards at ~110px wide require tight typography (10–11px) — readable but cramped. About / Team / Gallery / Timeline live below the fold.
