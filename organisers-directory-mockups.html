Organisers directory — layout proposals

Three approaches that address the same five problems with different discovery strategies. All preserve the existing OrganiserHoloCard visual identity and the floating Get Listed pill.

P1
3-col holo cards on mobile are cramped — all approaches drop to 2-col with larger, readable cards.
P2
No filter discovery — each approach surfaces category filtering proactively (chip rail, sectioned browse, or both).
P3
No active signal — each card now shows “Next: <date>”; live pip + Tonight highlight for organisers with an event today.
P4
No search — persistent search input in all three layouts.
P5
Get Listed CTA hidden at bottom — pinned floating pill anchored to viewport, visible from the first scroll position.
A

Compact filter rail

Sticky search + chip + sort row above the grid. Cards stay in a single visual flow; filtering happens inline without leaving the page.

  • Best when: users know roughly who they’re looking for (name, city, category).
  • Trade-off: least guidance for first-time browsers.
