## Findings

1. **Should-fix** `src/modules/organiser/p3/data/history.ts` (`WHO_OF` lookup in `parseHistoryItem`, `who:` line): `WHO_OF` is a plain object, so `who: "constructor"` (or `toString`, `__proto__`) is truthy and `who` becomes a function, not `'someone'`. Probed in vitest: `typeof who === 'function'`. `whoWord` then returns `undefined` and the who word silently vanishes from the sub line. The RPC only emits three words today, so it is latent, but the brief asks that an unknown `who` read "Someone". Fix: `Object.hasOwn(WHO_OF, o.who)` or a `Map`, plus one matrix case for `constructor`.
2. **Should-fix** `data/history.ts` (`isHistoryRefusal`) vs `src/modules/organiser/shared/selfServeErrors.ts:304` (`isAccessRefusal`): two refusal mappings. History's treats `permission_denied: authentication_required` and code `42501` as "not yours"; the shared one deliberately does NOT treat a signed-out caller as a refusal. Brief item 2 asked for ONE mapping. In practice `WorkspaceGate` has already used `isAccessRefusal` before History mounts, so the divergence only bites on a mid-session sign-out. Fix: build `isHistoryRefusal` on `isAccessRefusal` plus the RPC's own `42501 / not_a_member / not_signed_in`, and state why `authentication_required` differs.
3. **Should-fix (low)** `screens/HistoryScreen.tsx` (the `!days.length` branch): if page 1 has `has_more` but every row on it is dropped as malformed, `days` is empty, the empty card ("Nothing has changed yet") shows and "Show older changes" is never drawn, so older real rows are unreachable. Show the button (or auto-fetch the next page) when `q.hasNextPage` even if `days` is empty. Pinned by no test.
4. **Nit** `data/history.ts` (the `sub` line) and comment: raw `·` (U+00B7) in a `.ts` string, and the same in `history.matrix.test.tsx` expectations. CLAUDE.md says no raw Unicode punctuation in source; use `·` (as `labels.ts` does for the ellipsis).
5. **Nit** `screens/HistoryScreen.tsx` (`q.isError && !q.isFetchNextPageError`): a failed background refetch of an already-loaded list (query is `staleTime 30s`) sets `isError` with data present and replaces the rows with the error card. Guard with `!q.data` so loaded rows stay.
6. **Nit** `screens/HistoryScreen.tsx` (`enabled: !!user?.id`): with no user the query is disabled and `isPending` stays true, so the loading card shows forever. Unreachable behind the auth gate; one-line comment is enough.
7. **Nit** `history.matrix.test.tsx` (grouping tests): the BST end (25 Oct) is covered; the start (29 Mar 2026, 23:00 UTC is already 30 Mar) is not. I probed `Intl` on both: the grouping logic is correct, only the test is missing.
