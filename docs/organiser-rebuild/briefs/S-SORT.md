## The defect (in the owner's terms)
The owner asked that the Programme screen put sessions in start-time order by itself (no arrows). S-FEEDBACK built `sortSessions` in `src/modules/organiser/events/programmeSeriesModel.ts` (see `docs/organiser-rebuild/handovers/S-FEEDBACK.md`, "Item 4 decision") and sorts by plain clock start, so a session starting at 00:30 or 01:00 (an after-party on a Friday night) sorts FIRST, above the 19:00 class. The check that would have caught it: a table-driven sort test containing a 00:30 and a 07:59 session beside an evening session.
