1. **`flows/fix/NoDates*.tsx` not created.** C15 needs no screen of its own (the Home row already targets C8); a wrapper file would be dead code. The test lives in `flows/add/__tests__/add.flow.test.tsx` ("C15 no dates left").

3. **A changed time costs a second write.** `series.add_date` takes the day only (prod handler). An untouched time = exactly ONE command (tested). A different time = `series.add_date` then ONE `occurrence.set_time` on the new date (the id from the add's reply, its own event_view version). If that second write fails, Done still says what is true (the usual time) -- the date exists; Change a date fixes the time.
4. **Add uses `useOwnerCommand`, not `useRunCommands`**, for the reply's `occurrence_id` and the idempotency key; it still routes `series.*` to `series_command_p5` (asserted).
5. Shared step pieces live in `flows/add/{parts.tsx,useFlow.ts,addModel.ts}` and cancel imports them (both folders are S3's).
