# PR #1472: "Ask the team" links on organiser screens that send the person to the team

Brief: `docs/briefs/organiser-ask-us-links.md` (branch `brief/organiser-ask-us-links`).

## Design

**Chosen: one WhatsApp text link per place, under the words that are already there.**
The p3 screens reuse `.p3-link` (gold, underlined, `min-height: var(--tap)`). The event editor uses its own
link style (`flex min-h-[44px] items-center text-[14px] text-[var(--gold)] underline`, as in ProgrammeSeries).
Each link goes to `dancerMessageUsUrl(MESSAGE + context)`, the same as #1464's line-up link, so a message
arrives with the event name (plus the search text for a venue, and the reason shown for Repeat).

Why: it is the pattern #1464 already ships, `dancerMessageUsUrl` is always configured, and the URL builder
sits in a chunk every route already loads, so there is no new first-load request.
`supportLinks()` (organiser/shared/support.ts) is env-dependent and may return null, which could leave a dead end again.

**Rejected: a full-width secondary button ("p3-btn p3-btn-line") under each note.**
It is heavier than the note it supports. In the locked Repeat sheet it would sit next to the OK button and
compete with it as a second primary action. A link reads as "help is here" without becoming the main thing to do on the screen.
