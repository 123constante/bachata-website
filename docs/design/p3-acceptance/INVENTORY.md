- Lazy routes sit in `P3RouteBoundary` ("did not load" / "went wrong", Try again + back; `P3RouteBoundary.tsx:338`).
- Paths below are relative to `src/modules/organiser/` unless they start with `src/`. `series_command_p5` / `occurrence_command_p5` go through `shared/selfServeApi.ts:281-288`.
