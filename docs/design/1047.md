| C3 | W1 | Why |

| Rows open the event page | Rows are read-only; one link to the current organiser area | The P3 event page is a later slice; no dead control |
| Stats: Today / 7 / 30 days, chart or table, By event, date by date, where views come from | Same minus date by date and sources | Views: `organiser_series_stats_v1` (one 30-day read, ranges sliced). Date-by-date and sources are a follow-up (the RPC already returns `views_by_date` and `link_clicks_by_zone`). |
