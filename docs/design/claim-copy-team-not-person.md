# Claim copy: the team, never a named person

Brief: `docs/briefs/claim-copy-team-not-person.md`. Copy only; no database call, no hint change.

## Chosen wording
- No email on file: "This page has no email on file yet. Ask to join and the Bachata Calendar team will check and get back to you."
- Page with members (hint `managed`): title "<name> already has a team"; sub unchanged.
- End warning: "Only the Bachata Calendar team can reopen an ended event."

Why: organisers read "the team" as the product, not one person, and the copy makes no timing promise. The `managed` hint only means the page has members; the client cannot tell managers-only from owned, so "owner" was a claim the screen could not back. "Owner" stays only on the `yours` state, where it is true.

## Rejected
- "Ask to join and we will check, usually the same day." Promises a timing nobody committed to.
- "<name> already has an organiser." Still an unproven claim about roles the hint cannot see.
