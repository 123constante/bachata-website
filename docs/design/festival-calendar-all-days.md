# Festival calendar: every day it runs

**Design Gate: fix only, no new visuals.**

A multi-day festival now appears on every day it runs in the city page's
All-Events feed (it was folded into its first day), and the Calendar tab's day
sheet now loads the last day of the month (it opened as "No events found").
Both use existing components unchanged: the festival row keeps its existing
date-range badge on each day, and the day sheet is the existing
`DayDetailModal`. No new layout, colour, copy or control.
