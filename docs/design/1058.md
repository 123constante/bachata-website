# Design record: PR #1058, P3 W2c "Cancel the event" on a one-off (2026-10-27)

Brief: `brief/p3-cancel-one-off` `docs/briefs/p3-cancel-one-off.md` (sha 927194ae). Flag `organiserP3` stays OFF.
Dispatch ticket `dt_c336912f28f2`. Stages 5 and 6 are the orchestrator's.

## Brief
- **Who:** an organiser on a phone (390x844), on a one-off that has not happened yet.
- **One job:** end the event with a reason, so dancers see "Cancelled" and why, and be able to bring it back.
- **Feel:** C3 `cancelnext` (one-off wording) in the existing P3 bottom sheet.

## What matches C3, and what does not (and why)
| C3 / brief | W2c | Why |
|---|---|---|
| `endit` disabled before the first date: "Take it off the calendar instead" | "It hasn&rsquo;t run yet, so it can&rsquo;t end. Cancel the event instead." when Cancel works; the W2a reason otherwise | Point at the row that works, never at a dead end |
| "Cancel the event" next to `endit` | Same row slot; enabled by ONE rule (`canCancelOneOff`) | Brief item 5 |
| Greyed with a reason, never hidden | Started / passed (use End it), hidden (show it first), already cancelled, not exactly one date | Brief item 5; draft and finished states keep their own rows (no Cancel row) |
| Title "Cancel &lt;name&gt; on &lt;full date&gt;?", body, reason picker, "Yes, cancel the event" off until a reason | Same; every `cancellation_reasons` label is offered, Other included | One reason list; the server needs a label |
| Toast "Cancelled. Bring it back" | Same; Bring it back = `occurrence.cancel {cancelled:false}` on the date | AD4 undo path; no new command |
| `already_cancelled` = success, stored reason | "It was already cancelled. Dancers see: &lt;reason&gt;." | Never a second "Cancelled" |
| Date sheet "Cancel this date" on a one-off opens the same sheet | NOT BUILT | No date sheet exists on the P3 event page yet (W2b); stated in the PR |
