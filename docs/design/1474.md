## Design

- Label "Ambassador"; tapping it opens "Helps new organisers join their city".
- Asks `is_claimed_profile_ambassador_v1(p_profile_id uuid) -> boolean` (admin repo; applied on prod, granted to anon and authenticated). It is true only when the `dancer_profiles` row is claimed (`claimed_by` not null), not archived, and the claimer is a city ambassador in `entity_members`. So the badge shows ONLY on a claimed page.
- Every page passes a `dancer_profiles.id`: the person snapshot id, and the DJ and teacher ids (both `get_public_dj_v1` and `get_public_teacher_detail_v1` read `dancer_profiles`; read back on prod 2026-11-08).
- Renders nothing unless the answer is exactly `true`. An error, null, rejected or thrown call means no badge and no error UI.
- Replaces the old `is_city_ambassador_public_v1(p_user_id)` call. That call passed a profile id as a user id: only 49 of 206 profile ids happen to equal an auth user id.
