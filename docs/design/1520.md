## Going line (6.4-r05, T4 / Q16)
- Source: `get_my_series_going_v1` (owner / managers of the series; `event_attendance` itself is self-only under RLS, read 2026-11-10). Read only while the Tickets sheet is open.
- Shown only when nothing on the event is paid (a paid type's sales already say it) and at least one tap on a night that still happens. Cancelled nights count for nothing.
- Copy: "Going: 7 people are going to the next 2 dates. Free event: no money is taken here." No amount for any role.

## External link line (6.4-r09, X5)
- Source: the event workspace already on screen (`admin_event_workspace_p5`, same query key as the event page: no second request): the series' `default_ticket_url`, else a date's own link.
- Shown only when the event has a link and NO ticket types here. Then the empty state drops the "paid ones need payments connected" hint and the Stripe return banner is not shown (no payment controls).
- Copy: "This event sells tickets on its own link (host), not here." Host only, never the URL's tracking.
