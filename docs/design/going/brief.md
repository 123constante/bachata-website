# Design Gate stage 1 &mdash; Going P0 brief

- **Who:** a London bachata dancer on a phone (390x844), usually signed in with an unfinished profile (140 of 170 profiles are incomplete, mostly missing dance role); organisers checking their own nights.
- **One job:** say "I'm going" to ONE specific night and see who else is going (count + opted-in faces); organisers see the same for their nights.
- **Feel:** warm and social, never pushy; at launch every night shows 0 going (271/271 upcoming nights), so zero must read as an invitation.
- **Fixed by owner (2026-10-23):** one "I'm going" button (no Interested), finished profiles only (DB-enforced), per night not per series, one "Show me as going" switch OFF by default covering event faces and the dancer page's "Going next".
- **This pass:** stages 1-2 only &mdash; shape survey (`docs/going/shape-survey.md`) + three whole-feature options A/B/C (`docs/design/going/option-*.html`), no product code.
