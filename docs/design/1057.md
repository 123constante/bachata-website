## What matches C3, and what does not (and why)
| C3 | W2a | Why |
|---|---|---|
| ONE status row "Live &middot; Hide or end it" (probe F13) | Same | |
| Hide asks first ("Hide Sensual Fridays?") | Hide sends at once and the toast offers Undo | Brief item 5: Undo where reversible; Show is the exact inverse |
| Back to draft (a live move in C3) | Shown greyed: "A live event can&rsquo;t go back to draft. Hide it instead&hellip;" | CONTRACT 2: not an owner transition |
| End it: "Did tonight happen?", no default, Next off until answered | Same; payload `today_session` only when a date is today | `_cmd_series_end_run_p5` requires it then |
| End it greyed before the first date | "It hasn&rsquo;t run yet, so it can&rsquo;t end. Hide it or remove it instead." | The server refuses an event with no evidenced night (that refusal also has copy) |
| Stop repeating: keep-these-dates checklist (6 dates) | Every date after today listed, all ticked to start | Untouched = keep everything; the server never touches today or earlier |
| Stop repeating on a course | Greyed: "A course keeps its dates while it runs&hellip;" | The server refuses a live/paused course |
| Cancel the event (one-off) | One greyed `StatusRow` slot with a real reason (cancel its date in the current area) | W2c mounts the cancel there |
| Remove (not drawn in C3) | Added, with a confirm step | Brief item 4: `->archived` |
| Sessions with per-date changes, "Different on N dates" | Series sessions only; a coming date with its own changes gets an "Own changes" chip | The workspace carries counts, not the per-date sessions (W2b) |
| Line-up role nouns | teacher / DJ / performer | A stored `mc` role (1 prod row) has no C3 word and is not shown rather than mislabelled |
