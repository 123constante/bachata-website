## Brief
- **Who:** a newcomer to London bachata, on a phone (390x844).
- **One job:** discover the people behind the nights (dancers, DJs; teachers soon) and tap through to one.
- **Feel:** warm and social.
- **This pass:** the owner's screenshot showed a hard colour step where the cool dark hero meets the warm
  brown wall ("why is there still a color change between the black and the dark green?"). Fix that seam
  and only that.

## Options chosen (owner)
- Keep today's hero (content, colours, height untouched), then the filter pills, then the face wall.
- Seam: **soft fade** (owner click). No restyle of the hero; only the join blends.
- Same soft treatment for the wall -> next section seam, which had the same hard step (measured below).

## Tokens used (`src/modules/person-page/wall/tokens.ts`)
- `SEAM.clear` = `rgba(30, 20, 16, 0)` (the warm base at alpha 0, so the fade never passes through grey)
- `SEAM.base` = `WALL.page` = `#1E1410`
- `SEAM.height` = `64` px
- `WALL_FADE`: the wall's background as two gradient layers, top layer `clear -> base` over the first 64px,
  bottom layer `base -> clear` over the last 64px (each 51% tall so they overlap; no `calc()` stops).
  `minHeight` 128px (2 x SEAM.height) so a short wall still reaches the solid base.
  Used by `PeopleWall` (`data-testid="wall-root"`) and `WallSkeleton`, both marked `data-seam="soft"`.
- Why the fade starts from clear and not from the sampled hero colour: the page ground behind the hero is
  a fixed layer that differs per page (/dancers default palette, which animates; /djs `dj` ground), so a
  fixed start colour would draw a new edge somewhere. Clear lets the real ground show through, whatever it is.
  Sampled colours are recorded in the `SEAM` comment and in the table below.
- No layout box added: pill and tile positions are unchanged (`firstTileTop` 594 /dancers, 419 /djs, as the
  layout pass).
