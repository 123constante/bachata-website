## Design chosen: pencil inline at the end of the sentence

- The pencil is the existing `AboutSlot` (the same `PencilButton field="bio"`, 44x44 explicit px, "Edit about"), placed as an inline-flex element after the sentence's last word. It flows like a word, so it wraps with the text and cannot sit over a word at 390px.
- It needs no extra row and reads as "this sentence -> edit it", which keeps the hero compact (design-density rule).

## Rejected: pencil on its own line under the sentence

- A separate 44px row under 2-3 wrapped lines adds about 44px of hero height for one icon. That goes against the compact rule, and on /page it stacks under the text in a column that already has a right-hand pencil slot.
- It also splits the control from the copy that asks for it, so the pencil reads as unrelated to the sentence.

## Continuation 1: one About pencil per screen (option a chosen)

Round 1 made `slot('about')` return null with no bio, which removed the owner-blank "Add a bio" pill's pencil from #1471 (`visibility.matrix` red, 4 rows). Now `slot('about')` always renders its pencil again, as on main.

- **Chosen (a):** the `about` pencil registers while mounted (`AboutSlot register`, a layer counter); `about-empty` drops its own pencil when one is mounted. It covers all three callers (public hero, owner-blank pill, /page About row) inside the layer.
- It needs no edit to `src/pages/OrganiserProfile.tsx` (brief: page edits only if the only fix) and no caller has to know the rule.
- **Rejected (b):** the public page renders only one of about / about-empty. That moves the rule into `OrganiserProfile.tsx`, which already picks one per hero; the duplicate comes from the separate pill, so (b) would hide the hero line in the blank state.
- (b) would also leave /page (which renders both slots) needing its own copy of the same rule: two copies of one fact.

Trade-off of (a): on first mount one frame could hold both pencils; `useLayoutEffect` registers before paint, so none is painted.
