# Design record: PR #1098, P3 W3b-1 History (read only)

Source drawing: C3 mockup `docs/organiser-rebuild/p3/mockups/C3.html` on `claude/er-p3-c3-test`, screen `history` (`R.history`) and its entry row in the event page's "More options" fold.

| C3 element | Built | Matches C3 / does not and why |
|---|---|---|
| Back link to the event, event name above the title | `&larr; <event name>` link, then the title | Matches in substance. C3 puts the name as a small "when" line above the title plus a separate BACK; P3 already uses "&larr; name" as the back link on All dates, so one pattern across P3 screens. |
| Title "History" | `L.history` (already in `labels.ts`) | Matches. |
| Intro "Every change, who made it and when." | `L.historyIntro` | Matches word for word. |
| One card of rows, each: what changed, then "who &middot; when" | Rows grouped into one card per London day (day heading "Friday 6 March"), row title = RPC `label`, sub line = "You &middot; 14:32 &middot; for Friday 6 March" | Does not exactly: the brief asks for day groups, so the "when" splits into a day heading plus a time. Same information, less repetition on long lists. |
| Avatar circle with the who initial | Not drawn | Does not. The who word is already in the sub line; with only three who values ("You", "A co-host", "The Bachata team") the circle adds height without new information, and density rules ask for compact rows. |
| Changed fields | Extra line "Changed: Name, Price" from the RPC `fields` | C3 has no such line; the brief asks for it. |
| Undo button / "Undone" / "why not" line | Not drawn | Does not, by the brief: Undo waits for admin A3 R2. No copy points at Undo. |
| Empty: "No changes yet / When you or your team change something, it shows here." | "Nothing has changed yet / When you edit this event, it shows here." + "Back to the event" link | Does not word for word: the brief fixes this copy and asks for a way back. |
| Event-page entry "History &middot; Every change, who made it, Undo where it can" inside "More options" | A "History" row appended to the event page's edit rows card, sub "Every change, who made it and when" | Does not: P3's event page has no "More options" fold yet, and the sub drops "Undo where it can" because there is no Undo. |
| (not in C3) Load more | "Show older changes" button at the bottom while `has_more` | Brief: a button, not infinite scroll. |
| (not in C3) Loading, error, refused | Loading card; error card with "Try again"; refusal = the exact `NotYoursCard` every P3 event screen shows | Brief. |

Tokens: only existing P3 tokens (`--fg`, `--mut`, `--gold-fg` on `--card` / `--bg`); no new CSS. Taps: links and buttons use `--tap` (44px). Walked at 390x844 and 360x640, light and dark, no sideways scroll.
