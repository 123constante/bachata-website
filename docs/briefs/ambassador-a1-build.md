## Build
- Route `/ambassador` (lazy, own chunk; NOT in any nav, no link anywhere: A4 links it later). `buildBreadcrumbs(routeId, ctx)` per the rule. Review screen = `/ambassador/review/:targetType/:targetId` (or in-page state, your call; keep browser Back working: Back from a review returns to the list at the same scroll position).
- Access: call `admin_get_my_city_scopes()` (authenticated, returns city_id, city_name, city_slug for the signed-in ambassador). Signed out -> the site's normal sign-in path. Signed in with NO city scopes -> the mockup's "wrong city / no access" state (calm, says what they can do). An admin who is not an ambassador is out of scope: treat as no access unless the RPC returns scopes.
- Queue: `admin_list_pending_review_v1(p_target_type null, p_city_id <scope city>, p_limit 100, p_offset 0)` per scope city; the RPC returns NEWEST first and hides submitter email for non-admins: you MUST sort OLDEST first on the client and MUST NOT render or request any email. NOTE `submitted_at` is really `updated_at`, so the chip says "Waiting N days" meaning "last changed", fine; do not claim "submitted". A list of exactly 100 rows must say there may be more (page with p_offset; do not silently cap).
- Decisions: `admin_approve_entity_v1(p_target_type, p_target_id, p_reason null)` and `admin_reject_entity_v1(p_target_type, p_target_id, p_reason)` (reject reason REQUIRED, min 10 chars, inline error, exactly the mockup's sheet). The RPC has NO "you are party to this" flag: when approve/reject returns the error `self_approval_not_allowed`, turn that row into the mockup's "needs an admin" state locally (no buttons, says why) and keep it in the list. Map every other error code to a readable message with a Retry, never a raw code. After a success the item leaves the list, count updates, toast says what happened and how many are left (mockup copy).
- Use React Query for all async, `cn()` + Tailwind, RPCs not table reads, existing supabase client pattern (find how other Website modules call RPCs; follow it). New code under `src/modules/ambassador/`. No `dialog.tsx` changes (shared primitive; build the sheet with what exists or a local component). HTML entities, never raw Unicode punctuation.
- Weekday names in full. British English. Dates are London calendar dates.
