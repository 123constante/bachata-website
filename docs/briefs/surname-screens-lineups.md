## Finding (another session walked the #746 preview, signed out, owner's Chrome)
On the preview, `/event/abcd-any-body-can-dance-2027` renders teacher links `/teachers/<uuid>` as full names ("Daniel Carbonero", "Iman Anwar", "Mariana Petryk", "Julian Mr M"), byte-identical to production. `/event/budapest-bachata-festival` shows couples "Carlos & Paz". Production has 0 hidden surnames today, so "identical to production" proves nothing about masking; the question is whether the line-up path CAN leak.
