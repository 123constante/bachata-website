2. **Decision calls.** Read the LIVE bodies with the read-only Supabase connector: `admin_approve_entity_v1`, `admin_reject_entity_v1`, `_moderate_entity`, `tg_enforce_lifecycle_transition`, `admin_get_my_city_scopes`, `admin_list_pending_review_v1` (prod project `stsdtacfauprzrdebmzg`; SELECT on pg_proc only).
