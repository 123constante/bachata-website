Location Banner — 6 Visual Options

Compare six distinct treatments for the proximity-sort banner above the event grid. All are mobile-first and density-compliant. The current implementation is shown at the bottom for reference.

Pick A–F by label. Each is shown in its idle state (the most-seen first impression).

A

Radar Pulse

Animated concentric rings around the pin — feels like "scanning for events nearby". Strong centrepiece energy.

B

Frosted Premium

Glassmorphic surface with animated light-sweep. Restrained but feels high-end.

C

Gradient Hero

Bold sweeping gradient (orange → pink → violet). Highest visual impact — owns the page.

D

Glow Border

Dark surface with pulsing orange glow halo. Calmer than C, more present than the current pill.

E

Map Texture

Subtle dot-grid evokes a map. Storytells "location" without a literal map render.

F

Compass Card

Spinning compass icon + 2-line copy. Playful and informative without shouting.

State coverage

Whichever style you pick will be applied to the four states: idle (shown above), loading (spinner replaces the icon), granted (green confirmation strip with "Clear" affordance), and denied / unavailable (muted info strip). The visual language carries through — only colour and content swap.
